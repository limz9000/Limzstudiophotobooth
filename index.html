✨ Fitur Lengkap Limz Studio Photobooth

Solusi terintegrasi dokumentasi foto cloud, live stage, dan interaksi tamu.

☁️ Auto-Sync Google Drive Kilat
Sistem otomatis mendeteksi setiap foto baru yang masuk ke folder Google Drive dan menampilkannya secara langsung di galeri tamu tanpa perlu upload ulang.
🖥️ Layar Monitor Panggung Interaktif & Smart QR
Tampilan panggung mewah dengan tipografi elegan. Setiap foto utama maupun sub-foto dilengkapi stiker QR Code tersendiri sehingga tamu bisa langsung memindai dan mengunduh foto spesifik mereka.
🎨 Watermark Canvas Fleksibel (WYSIWYG)
Bebas mengatur posisi sumbu horizontal (X), vertikal (Y), ukuran logo, dan opasitas logo PNG transparan Anda secara visual dengan simulator langsung.
🖨️ Flyer Meja Tamu 5 Tema & Download JPEG 4R
Generate flyer meja QR tamu dengan 5 opsi gaya tema (Royal Gold, Dark Obsidian, Botanical Sage, Rose Blush, Editorial Mono) serta fitur unduh file gambar JPEG standar cetak 4R (1200x1800 px).
💬 Live Doa Restu Tamu & Sensor Kata Kasar
Tamu dapat mengirim ucapan doa yang disiarkan di layar panggung dan galeri. Dilengkapi sistem moderasi cerdas dan penyaring kata otomatis untuk mencegah spam atau kata tidak sopan.
📊 Executive Summary PDF & Batal Arsip
Laporan analisis keterlibatan tamu format PDF siap kirim ke klien, manajemen kapasitas storage berkala, serta kemudahan mengarsipkan atau membatalkan arsip event sewaktu-waktu.

Pasang Aplikasi Limz Studio

Akses cepat layar penuh di Android, iPhone, iPad & Tablet.

🤖 Pengguna Android / PC (Chrome / Edge)

Pasang aplikasi langsung ke layar utama Android atau desktop Anda dengan 1-klik tanpa melalui Play Store.

🍎 Pengguna iPhone / iPad (Safari)
  1. Buka tautan web app ini di browser Safari iPhone atau iPad.
  2. Ketuk ikon Bagikan / Share (kotak dengan panah atas ⎋) di bilah navigasi Safari.
  3. Gulir ke bawah dan pilih opsi "Tambah ke Layar Utama" (Add to Home Screen).
  4. Ketuk "Tambah" di pojok kanan atas. Ikon Limz Studio akan muncul di Home Screen iPad/iPhone Anda!
📸

Panduan Sambung Kamera Sony, Canon, & Nikon

Tethering Wired (Kabel USB) & Wireless (WiFi) langsung ke Hot Folder Antrian.

💡 Cara Kerja Otomatis: Foto Tertahan di Antrian (Tidak Langsung Upload)

Kamera dijepret $\rightarrow$ Foto otomatis masuk ke folder laptop $\rightarrow$ Web app menyedot foto ke Meja Antrian (Staged Queue). Anda bisa meninjau komposisi, atur pencahayaan/grading Lightroom, lalu klik Upload saat sudah pas!

🔴 Kamera Canon EOS (Kabel USB / WiFi)

  • Gunakan software resmi Canon EOS Utility (Gratis dari Canon).
  • Sambungkan kamera via kabel USB atau WiFi ke laptop.
  • Di EOS Utility, pilih menu Preferences → Destination Folder (atur ke folder misal D:\Photobooth_Canon).
  • Di web app ini, klik tombol 📁 Tether (Hot Folder) lalu pilih folder tersebut.

🟠 Kamera Sony Alpha / ZV (Kabel USB / WiFi)

  • Gunakan software resmi Sony Imaging Edge Desktop (Remote) (Gratis dari Sony).
  • Di kamera Sony: Atur USB Connection: PC Remote (atau via Wi-Fi PC Remote).
  • Di aplikasi Sony Remote, setel Save Destination ke folder laptop (misal D:\Photobooth_Sony).
  • Di web app ini, klik tombol 📁 Tether (Hot Folder) lalu pilih folder tersebut.

🟡 Kamera Nikon (Kabel USB / WiFi)

  • Gunakan software resmi Nikon NX Tether atau Camera Control Pro.
  • Hubungkan kamera via kabel USB-C ke laptop.
  • Arahkan folder penyimpanan hasil unduh ke folder laptop (misal D:\Photobooth_Nikon).
  • Di web app ini, klik tombol 📁 Tether (Hot Folder) lalu pilih folder tersebut.

📱 Khusus iPad & Tablet (Koneksi WiFi / Kabel Type-C)

1. Sambungkan kamera (Sony/Canon/Nikon) ke iPad via aplikasi resmi (Sony Creators' App, Canon Camera Connect, Nikon SnapBridge) atau PhotoSync.
2. Di web app ini, klik tombol 📁 Tether untuk memilih folder tethering di aplikasi Files (File di iPad), atau klik 📱 iPad untuk memilih dari Album Foto.
3. Foto jepretan kamera otomatis masuk ke antrian (draft) dengan Lock Tone terpasang siap upload!

💻 Tips PC / Laptop: Hot Folder Auto-Sync Real-Time

Jika Anda membuka aplikasi melalui iframe Google Apps Script dan ingin pemantauan folder otomatis detik-per-detik tanpa klik: buka Web App di tab browser mandiri (bebas iframe).

Integrasi Monitor+, Lightroom & Aplikasi Kamera

Hubungkan kamera nirkabel & software studio langsung ke antrian Limz Studio.

📱

1. Integrasi dengan Monitor+ (iPad / Android / PC)

Aplikasi Monitor+ sangat populer untuk monitor wireless kamera Sony/Canon/Nikon di iPad/HP.

  1. Buka aplikasi Monitor+ → masuk ke menu Settings → Auto Download.
  2. Aktifkan "Auto Download After Shutter" dan arahkan folder simpan ke folder lokal (misal: Files/LimzStudio atau Camera Roll).
  3. Di web app Limz Studio, klik 📁 Tether (pilih folder yang sama) atau klik 📱 iPad.
  4. Setiap jepretan dari Monitor+ akan langsung otomatis diserap ke antrian dengan Lock Tone terpasang!
🎨

2. Integrasi dengan Adobe Lightroom Classic

  1. Di Lightroom Classic, buka menu File → Auto Import → Auto Import Settings.
  2. Centang "Enable Auto Import".
  3. Tentukan Watched Folder (folder jepretan kamera) dan Destination Folder (folder hasil ekspor Lightroom).
  4. Di Limz Studio, klik 📁 Tether lalu pilih Destination Folder tersebut. Foto hasil grading Lightroom akan langsung masuk ke antrian Limz Studio!
⚡

3. Integrasi PhotoSync / WiFi FTP

Gunakan aplikasi PhotoSync di iPad/ponsel untuk transfer otomatis via Wi-Fi dari kamera ke folder target secara berkala (Trigger on Receive).
